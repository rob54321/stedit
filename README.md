stedit.pl is a replacement for sed. It is a stream line editor written in perl. Four editing commands are implemented. Append, substitute, delete and insert. They all work with Perl regular expressions.
Modifiers can be use with each command to alter its function. Commands can also be run from a script file and all commands are executed in the order they are given on the command line or in a script file.
Commands can be supplied by command line and/or script file in the same session. The file differences between the edited and original files can be displayed in colour. The file can be written/ not written
to any file name.
